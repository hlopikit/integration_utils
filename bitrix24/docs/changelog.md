# Changelog

## 2026-10-28 (локально, #328153)

- `start` читает `return_to` из разобранного `PLACEMENT_OPTIONS`, сохраняя приоритет GET и резервный источник HTTP Referer. Невалидные и внешние адреса игнорируются.
- При возврате сохраняются query-строка, повторяющиеся GET-параметры и fragment; управляющий `return_to` больше не дублируется внутри `bx_referer_params`.
- В существующий `tests.py` добавлены проверки Marketplace-входа без cookie, источников адреса возврата и совместимости обычного iframe-запуска.

## 2026-09-13

- `main_auth(on_start=True)` возвращает контролируемый HTTP 401 при ответе Bitrix24 `invalid_token`, а не необработанный HTTP 500.
