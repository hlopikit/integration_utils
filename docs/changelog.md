# Changelog

## 2026-10-08

- `main_auth(on_cookies=True)` для GET/HEAD без действующей cookie теперь направляет браузер в Marketplace-приложение из настройки проекта `BITRIX_MARKETPLACE_AUTH_APP_ID` и возвращает на исходный безопасный относительный адрес после iframe-входа. Небезопасные методы и проекты без настройки сохраняют 401, чтобы не потерять операцию.
- Общий Marketplace start endpoint теперь принимает только безопасный относительный `return_to`: после `main_auth` и установки cookie пользователь может вернуться на защищённую страницу itsis, а не только на стандартную стартовую страницу приложения.

## 2026-09-05

- Добавлен исходник будущей статьи БЗ о `RetryDecorator`: контракт декоратора, порядок повторных попыток, применение в Bitrix24-клиенте и ограничения безопасного использования.

## 2026-08-14

- Добавлен исходник будущей статьи БЗ о разборе `method_operating` и оптимизации вызовов Bitrix24 API.

## 2026-07-09
